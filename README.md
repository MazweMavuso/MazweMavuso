## 🏗️ Architecture & Approach

- **API-first** — Every project is built backend-out. Clean RESTful endpoints with proper validation, Sanctum auth, and consistent response structures before a single React component is written.
- **Service/Repository pattern** — Business logic lives in service layers, not controllers. Laravel apps are structured to scale, not just to ship.
- **Component-driven UI** — React components are reusable, prop-typed, and isolated. Animations with Framer Motion and GSAP are purposeful, not decorative.
- **Design-sensitive developer** — I care about typography, spacing, and motion. Dark cinematic UIs with strong brand systems are my default aesthetic.
